## Description
**HealthCenter Hospital Website** is a responsive, modern frontend web application designed for a hospital or healthcare center.  
It provides information about the hospital, doctors, departments, services, patients, and contact information. Users can **book appointments directly** through a modal form.

Built using **HTML**, **CSS**, and **Bootstrap 5**, with smooth animations, interactive modals, and Google Maps integration.

---

## Features
- Responsive design for desktop, tablet, and mobile.
- Sticky navbar with dropdown menus for **Doctors** and **Departments**.
- Banner section with welcome message & call-to-action button.
- About section describing the hospital.
- Doctors section with profile cards including images, specialization, and descriptions.
- Services section highlighting key departments: Cardiology, Neurology, Orthopedic.
- Patients table displaying information and status badges.
- Contact form to send messages.
- Google Maps embed showing hospital location.
- Modal for booking appointments with **toast notifications**.
- Back-to-top button for smooth navigation.
- Footer with quick links, contact info, and social media icons.
